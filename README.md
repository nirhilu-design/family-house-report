# מחולל דוח תמצית – Family House

כלי דפדפן שמקבל את **הדוח התקופתי של JP Group** (PDF, ~16 עמודים), מחלץ ממנו את הנתונים, מציג את **שיוך כל שדה** בדוח התמצית לעמוד המקור, מאפשר לתקן ולהשלים, ומייצא **דוח תמצית של שני עמודי A4** ללקוחות Family House.

- **פרטיות:** הקובץ נקרא ומעובד בדפדפן בלבד (pdf.js). אין שרת, אין העלאה, אין שמירת נתוני לקוח. בדפדפן נשמרים רק סיווגי נזילות/ערוץ לפי שם מנהל.
- **דטרמיניסטי:** אותו PDF → אותו דוח. אין AI בתהליך החילוץ.

## הפעלה

הקוד הוא קבצים סטטיים (ES modules), כך שצריך שרת מקומי פשוט – לא ניתן לפתוח את `index.html` ישירות מהדיסק.

```bash
# אפשרות א – Python (קיים כמעט בכל מחשב)
python -m http.server 8080
# אפשרות ב – Node
npx http-server -c-1 -p 8080 .
```

ואז לפתוח `http://localhost:8080`.

אפשר גם לפרסם כאתר פנימי (שרת קבצים סטטי ארגוני). שים לב: GitHub Pages לריפו פרטי דורש חשבון GitHub בתשלום.

## שימוש

1. **העלאת דוח PDF:** גרירה או בחירה.
2. **בדיקות תקינות:** המערכת בודקת שהסכומים מתאימים (מנהלים, אפיקים, חשיפות וערוצים מול השווי הכולל), שסטיית התקן חולצה לכל מנהל, ושחסרים מסומנים.
3. **שיוך נתונים:** כל שדה מוצג עם עמוד המקור ב-PDF וניתן לעריכה.
   - שם לקוח, הערות מנהל ההשקעות וחתימה: לא קיימים ב-PDF ומוזנים ידנית.
   - **נזילות:** לא קיימת ב-PDF. יש ברירת מחדל זמנית לפי סוג מכשיר, ואת הבחירה מאשרים. הבחירה נזכרת לדוחות הבאים לפי שם המנהל.
   - **ערוץ:** נגזר מעמוד "מבנה תיק מנוהל – ניהול תיקים" ונבדק מול עמוד הערוצים.
4. **ייצוא PDF:** פותח את חלון ההדפסה. בוחרים "שמירה כ-PDF", מוודאים ש"שוליים: ללא" ו"גרפיקת רקע" מסומנים.
5. **שמירת JSON:** שמירה של הדוח הממופה (כולל עריכות) לקובץ, לטעינה חוזרת מאוחר יותר.

## מבנה

```
index.html          ממשק: העלאה → שיוך → תצוגה מקדימה → ייצוא
css/report.css      עיצוב שני עמודי הדוח (794×1123px = A4)
css/app.css         עיצוב הממשק + סגנון הדפסה
js/extract.js       חילוץ מה-PDF: טבלאות לפי כותרות, סטיית תקן מגרפי היעילות (וקטורים)
js/model.js         בניית מודל הדוח + בדיקות תקינות + פורמט מספרים
js/render.js        רינדור שני העמודים מהמודל
js/config.js        ברירות מחדל שאינן ב-PDF (נזילות), צבעים, דיסקליימר
js/app.js           חיווט הממשק
vendor/pdfjs/       pdf.js (Apache-2.0)
fonts/              Carlito + Assistant (OFL) – גיבוי ל-Calibri
assets/             לוגו JP Group
tools/              CLI לחילוץ/רינדור בצד Node (לבדיקות)
tests/              בדיקות יחידה + בדיקת אינטגרציה מול PDF אמיתי
docs/               HANDOFF + מיפוי נתונים
```

## פיתוח ובדיקות

```bash
npm install
npm test                                   # בדיקות יחידה
FH_SAMPLE_PDF=/path/to/report.pdf npm test # + בדיקת אינטגרציה מול דוח אמיתי
node tools/extract-cli.mjs report.pdf --model > model.json
node tools/render-cli.mjs report.pdf preview.html
npm run vendor                             # עדכון pdf.js והגופנים בתיקיות vendor/fonts
```

**אין להכניס לריפו קבצי PDF או JSON של לקוחות** (חסומים ב-`.gitignore`).

## מגבלות ידועות

- החילוץ מותאם למבנה הדוח של JP Group, ומזהה טבלאות לפי הכותרות שלהן, לא לפי מספרי עמודים. שינוי בכותרות אצל JP Group ידרוש עדכון ב-`TITLES` ב-`js/extract.js`.
- סטיית התקן נקראת ממיקום הנקודות בגרף (וקטורי) ומותאמת למנהל לפי דירוג התשואה. דיוק של כ-±0.01 נקודת אחוז מול הגרף.
- Calibri עברית מוצג רק במחשב שהגופן מותקן בו (Windows/Office). בלעדיו: Carlito ללטינית ו-Assistant לעברית.
- מעל ~16 מנהלים, טבלת האחזקות בעמוד 1 עלולה לא להיכנס, ותופיע אזהרה.
